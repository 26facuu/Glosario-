     <h2>Glosario de Informática</h2>

        <p><strong>Archivo:</strong> Es un elemento de la computadora que permite almacenar información.</p>

        <p><strong>Carpeta:</strong> Sirve para ordenar y guardar archivos y otras carpetas.</p>

        <p><strong>Extensión:</strong> Son las letras que aparecen después del punto en un archivo para diferenciarlo de otro, por ejemplo .jpg o .txt.</p>

        <p><strong>CMD:</strong> Es la consola de comandos de Windows donde se pueden escribir instrucciones para la computadora.</p>

        <p><strong>Comando:</strong> Es una orden que le das a la computadora para que haga algo.</p>

        <p><strong>mkdir:</strong> Comando que se usa para crear una carpeta nueva.</p>

        <p><strong>copy:</strong> Comando que sirve para copiar archivos de una carpeta a otra.</p>

        <p><strong>echo:</strong> Comando que muestra un mensaje en la pantalla o escribe un texto.</p>

        <p><strong>Script:</strong> Es un conjunto de instrucciones que hace que una tarea se realice automáticamente.</p>

        <p><strong>Archivo .bat:</strong> Es un archivo que contiene una serie de comandos que se ejecutan automáticamente en CMD.</p>

        <p><strong>Google Drive:</strong> Es un servicio en la nube que permite guardar información, datos y archivos en internet.</p>

        <p><strong>Trabajo colaborativo:</strong> Es cuando varias personas trabajan juntas en un mismo proyecto desde diferentes lugares.</p>

        <p><strong>Scratch:</strong> Programa para aprender a programar usando bloques de colores.</p>

        <p><strong>Bloque:</strong> Cada pieza o instrucción que se usa en Scratch para crear un programa.</p>

        <p><strong>Algoritmo:</strong> Son los pasos que se siguen para resolver un problema o hacer una tarea.</p>

        <p><strong>Variable:</strong> Espacio de memoria que puede cambiar su valor mientras se ejecuta el programa.</p>

        <p><strong>Condicional:</strong> Es una estructura de programación que permite tomar decisiones según se cumplan o no ciertas condiciones.</p>

        <p><strong>Bucle:</strong> Es una estructura que repite una acción varias veces hasta que se cumpla una condición.</p>

        <p><strong>PSeInt:</strong> Programa que se usa para aprender programación creando algoritmos con pseudocódigo.</p>

        <p><strong>HTML:</strong> Es el lenguaje de marcado que arma la estructura de una página web.</p>

        <p><strong>CSS:</strong> Se usa para darle diseño y cambiar la apariencia de la página.</p>

        <p><strong>JavaScript:</strong> Sirve para agregar funciones e interacción, como botones o animaciones.</p>

        <p><strong>Etiquetas:</strong> Son las instrucciones que usa HTML para crear los elementos de la página.</p>

        <p><strong>Visual Studio Code:</strong> Es un editor de código donde escribimos programas.</p>

        <p><strong>IDE:</strong> Es un programa que reúne varias herramientas para programar de forma más fácil.</p>

        <p><strong>GitHub:</strong> Es una plataforma que sirve para guardar, compartir y trabajar en proyectos de informática de forma colaborativa.</p>

        <p><strong>Git:</strong> Es un sistema de control de versiones que guarda el historial de cambios.</p>

        <p><strong>Repositorio:</strong> Espacio donde se guarda un proyecto junto con su historial de cambios.</p>

        <p><strong>Control de versiones:</strong> Sistema que permite registrar los cambios de un proyecto y volver a versiones anteriores.</p>

        <p><strong>Commit:</strong> Registro o guardado de cambios con un mensaje descriptivo en un proyecto.</p>

        <p><strong>Rama (Branch):</strong> Versión independiente del proyecto que permite trabajar en cambios sin modificar directamente la rama principal.</p>

        <p><strong>Merge:</strong> Unir los cambios de una rama al proyecto o rama principal.</p>

        <p><strong>Push:</strong> Envía los cambios desde tu PC a GitHub.</p>

        <p><strong>Pull:</strong> Trae los cambios de GitHub a la PC.</p>

        <p><strong>Clonar (Clone):</strong> Crear una copia del repositorio en la computadora.</p>

        <p><strong>Git init:</strong> Comando que se utiliza para crear o iniciar un repositorio en Git.</p>

        <p><strong>Git add:</strong> Comando que prepara los cambios para poder guardarlos en un commit.</p>

        <p><strong>Git status:</strong> Comando que muestra el estado actual de los archivos y los cambios del proyecto.</p>

        <p><strong>alert():</strong> Muestra un mensaje en una ventana emergente.</p>

        <p><strong>prompt():</strong> Pide al usuario que ingrese un dato.</p>

        <p><strong>console.log():</strong> Muestra información en la consola.</p>

        <p><strong>if:</strong> Comprueba si se cumple una condición.</p>

        <p><strong>else:</strong> Se ejecuta cuando no se cumple la condición.</p>

        <p><strong>for:</strong> Repite instrucciones varias veces.</p>

        <p><strong>Math.random():</strong> Genera números aleatorios.</p>

        <p><strong>document:</strong> Permite acceder y modificar el contenido HTML.</p>

        <p><strong>getElementById():</strong> Busca un elemento HTML por su ID.</p>
